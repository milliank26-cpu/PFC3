# PFC image slots

Replace these starter SVGs with your own images using the same filenames, or update the relevant `image_url` values in the operator Game editor.

- `hero-banner-placeholder.svg` — wide PFC landing/hero artwork; recommended 1600×700 or 16:7.
- `game-image-placeholder.svg` — default game and competition card artwork; recommended 1200×600 (2:1).
- `avatar-placeholder.svg` — square player avatar fallback; recommended 400×400.

Game and competition artwork can also be managed by entering an image URL in the game's image field. Use images you own or have permission to use, and optimise them for mobile loading.
